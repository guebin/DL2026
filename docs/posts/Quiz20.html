1. 비효율적인 코드 (04wk. 5.J.)

- 아래의 두 코드는 모두 돌아가긴 하지만, (가)는 조금 비효율적이다.

(가)

Y = y.reshape(-1, 1)
X = torch.stack([torch.ones(100), x], axis=1)
net = torch.nn.Linear(
    in_features=2,
    out_features=1,
    bias=True
)
net.weight.data = torch.tensor([[-5.00, 10.00]])
loss_fn = torch.nn.MSELoss()
optimizer = torch.optim.SGD(net.parameters(), lr=0.1)
#---#
for epoch in range(30):
    Yhat = net(X)
    loss = loss_fn(Yhat, Y)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

(나)

Y = y.reshape(-1, 1)
X = torch.stack([torch.ones(100), x], axis=1)
net = torch.nn.Linear(
    in_features=2,
    out_features=1,
    bias=False
)
net.weight.data = torch.tensor([[-5.00, 10.00]])
loss_fn = torch.nn.MSELoss()
optimizer = torch.optim.SGD(net.parameters(), lr=0.1)
#---#
for epoch in range(30):
    Yhat = net(X)
    loss = loss_fn(Yhat, Y)
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

(가)

net = torch.nn.Linear(
    in_features=1,
    out_features=1
)
loss_fn = torch.nn.BCEWithLogitsLoss()

net = torch.nn.Linear(

3. FashionMNIST 분류를 위한 네트워크 설계

FashionMNIST 자료 5000장을 이용하여 10개의 클래스를 분류하려고 한다. 입력 이미지 X의 shape은 (5000, 1, 28, 28)이고, 레이블 y의 shape은 (5000,)이다.

다음 네트워크들을 고려하자.

(가) 단순한 네트워크

net_a = torch.nn.Sequential(
    torch.nn.Flatten(),
    torch.nn.Linear(784, 16),
    torch.nn.ReLU(),
    torch.nn.Linear(16, 10),
)

(나) 넓은 네트워크

net_b = torch.nn.Sequential(
    torch.nn.Flatten(),
    torch.nn.Linear(784, 4096),
    torch.nn.ReLU(),
    torch.nn.Linear(4096, 10),
)

(다) 깊은 네트워크

net_c = torch.nn.Sequential(
    torch.nn.Flatten(),
    torch.nn.Linear(784, 512),
    torch.nn.ReLU(),
    torch.nn.Linear(512, 256),
    torch.nn.ReLU(),
    torch.nn.Linear(256, 256),
    torch.nn.ReLU(),
    torch.nn.Linear(256, 256),
    torch.nn.ReLU(),
    torch.nn.Linear(256, 10),
)

(라) 넓은 네트워크 + Dropout

net_d = torch.nn.Sequential(
    torch.nn.Flatten(),
    torch.nn.Linear(784, 4096),
    torch.nn.Dropout(0.9),
    torch.nn.ReLU(),
    torch.nn.Linear(4096, 10),
)

손실함수는 모두 다음과 같이 사용한다.

loss_fn = torch.nn.CrossEntropyLoss()

다음 설명 중 올바른 것을 모두 고르시오.

(a) (가)는 은닉노드 수가 작으므로 표현력이 낮아질 수 있고, 그 결과 학습자료와 평가자료 모두에서 성능이 충분히 나오지 않을 수 있다.
(b) (나)는 은닉노드 수가 매우 많으므로 표현력이 좋아진다. 하지만 학습자료에 지나치게 잘 맞아 오버피팅 위험도 커질 수 있다.
(c) (다)는 레이어를 깊게 쌓았으므로 항상 (나)보다 평가자료에서 좋은 성능을 낸다.
(d) (라)의 Dropout은 네트워크의 표현력을 키워주는 장치이므로, Dropout을 넣으면 학습자료를 더 잘 외울 수 있다.
(e) (라)의 Dropout은 오버피팅 위험을 줄이기 위한 장치로 볼 수 있다. 단, Dropout을 넣었다고 해서 평가 성능 향상이 항상 보장되는 것은 아니다.
(g) 위 네트워크들은 모두 마지막에 10개의 값을 출력하므로, 그 값들은 CrossEntropyLoss에 들어가는 logits로 해석할 수 있다.
